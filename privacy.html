Privacy policy

Last updated: 20 November 2026.

Channel Command Center is used only by its owner, on YouTube channels he owns.

What it accesses

With the owner's consent, through the YouTube Data API and the YouTube Analytics API, it uploads videos, sets their titles, descriptions, thumbnails, playlists and publish times, and reads the channels' videos and analytics.

How the data is used and kept

The data is used only to run those channels. The OAuth tokens and the data read are kept on the owner's private server. Nothing is sold, shared with third parties, or used for advertising.

Channel Command Center's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services and is bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions; stored tokens are then useless and are deleted.
